01 — one program, every layer

gpt-oss-20b runs on NVIDIA and AMD GPUs, with every layer in Raven.

Each layer of the model, attention and a mixture of experts, compiles into GPU kernels under Rune.jit. Six libraries carry a prompt to its answer without leaving the language.

  1. ᚨbrottokenizes the prompt
  2. ᚴkaundefines the model
  3. nxholds the weights and the cache
  4. ᚱrunecompiles each layer
  5. ᛏtolkturns it into GPU kernels
  6. rigruns them on the GPU

98 tok/s

decoding gpt-oss-20b on an RTX 5000 Ada, jitted, one token per 10.2 ms step. llama.cpp: 146 tok/s. The goal post on the road to 1.0: at least as fast as four baselines.

03 — why raven

Prototype like Python. Ship like OCaml.

i.

Dtype and device mistakes stop at the compiler.

An array's type carries its dtype and the device set it lies on, so values from two device sets never meet by mistake. Shapes are checked when an operation runs. Why Raven →

ii.

JAX's ergonomics, in a real functional language.

Every Nx function issues a small set of primitive operations. grad, vmap and jit are OCaml 5 effect handlers that interpret them, so they nest like any other function.

iii.

GPUs with no CUDA, no ROCm, not even a driver.

rig drives NVIDIA and AMD GPUs through their kernel drivers, or, on Linux, with no driver at all: it boots the GPU itself from the vendor's firmware. Precompiled kernels run with nothing else installed; compiling them at run time loads NVRTC or comgr. On the road to 1.0: your whole application, model included, as one static binary. rig →

05 — roadmap

The road to replacing a Python stack in production.

full roadmap →

  1. alpha · 2025-11

    The libraries, eager on the host.

    FFT and a full linear algebra suite in Nx, dataframes in Talon, and the decision to port tinygrad to OCaml.

  2. beta 1 · done

    Compiled, on GPUs.

    A whole training step compiles into one GPU program, with every layer in Raven.

  3. toward 1.0 · now

    gpt-oss, against the fastest.

    Jit-compiled gpt-oss-20b at least as fast as tinygrad, JAX, llama.cpp and vLLM, on NVIDIA and AMD.

  4. 1.0 · next

    Replace a Python stack in production.

    Training and deployment, each at 90% or better of the Python stack it replaces.
