# Input and output

`Nx_io` loads and saves tensors in image, NumPy, SafeTensors, and delimited text
formats, and loads GGUF. Files of named tensors are read and written as
archives, and values made of tensors are saved and loaded through their
structure.

## Images

`load_image` recognizes static PNG and JPEG streams from their contents. It
returns an RGB `uint8` tensor by default, or a two-dimensional grayscale tensor
when requested.

<!-- $MDX skip -->
```ocaml
let rgb = Nx_io.load_image "photo.png"
(* Nx.shape rgb = [| height; width; 3 |] *)

let gray = Nx_io.load_image ~grayscale:true "photo.jpg"
(* Nx.shape gray = [| height; width |] *)
```

`save_image` selects PNG or JPEG from the destination extension. It accepts
`uint8` tensors with these shapes:

- `[| height; width |]` or `[| height; width; 1 |]` for grayscale;
- `[| height; width; 3 |]` for RGB;
- `[| height; width; 4 |]` for PNG RGBA output.

<!-- $MDX skip -->
```ocaml
Nx_io.save_image "copy.png" rgb;
Nx_io.save_image ~overwrite:false "thumbnail.jpg" thumbnail
```

The default is to replace an existing destination atomically. Pass
`~overwrite:false` when replacing an existing file would be an error.

## NumPy arrays

### NPY files

An NPY file carries a dtype that is known only at runtime, so `load_npy` returns
a packed tensor, an `Nx.packed`.

<!-- $MDX skip -->
```ocaml
let packed = Nx_io.load_npy "data.npy"

let data = Nx.unpack Nx.float32 packed
(* [Nx.unpack] raises [Invalid_argument] if the file contains another dtype. *)

Nx_io.save_npy "copy.npy" data
```

Pattern matching is useful when code can operate without fixing the dtype:

<!-- $MDX skip -->
```ocaml
let describe path =
  let (Nx.P tensor) = Nx_io.load_npy path in
  (Nx.dtype tensor, Nx.shape tensor)
```

NPY versions 1.0, 2.0, and 3.0 are accepted. Nx reads and writes boolean,
16/32/64-bit floating-point, 8/16/32/64-bit signed and unsigned integer, and
64/128-bit complex arrays. Both C and Fortran input order and either byte order
are accepted. Dtypes without a standard NPY representation, such as bfloat16,
float8, and 4-bit integers, cannot be saved. A `bit` mask is saved as
`Nx.cast Nx.bool m`, one byte per value, or as its packed bytes,
`Nx.bitcast Nx.uint8` of the mask padded to a multiple of 8.

## Named tensors

A model, an optimizer state or a dataset is a set of tensors, each with a name.
Files that hold such sets (NPZ, SafeTensors, GGUF) are read and written as an
`Nx_io.Archive.t`: an immutable collection of tensors keyed by distinct,
non-empty names. Each format has a pair of functions named after it.

<!-- $MDX skip -->
```ocaml
let a =
  Nx_io.Archive.of_list
    [ ("weights", Nx.P weights); ("labels", Nx.P labels) ]

let () = Nx_io.save_safetensors "data.safetensors" a
let () = Nx_io.save_npz "data.npz" a

let names = Nx_io.Archive.names (Nx_io.load_npz "data.npz")
(* ["labels"; "weights"] *)
```

An entry's dtype is known only at runtime. `Archive.tensor` asks for one at the
dtype and shape the program expects, and fails naming the entry when the file
holds anything else:

<!-- $MDX skip -->
```ocaml
let a = Nx_io.load_safetensors "data.safetensors" in
let weights = Nx_io.Archive.tensor ~shape:[| 784; 10 |] Nx.float32 "weights" a
```

`load_safetensors` reads the file's header and none of its tensors. Each entry
stays in the file, on the disk device, until an operation reads it: the host
computes on the file's pages where they lie, and placing an entry on a device
copies it there. The file must not change in place while an entry loaded from
it is alive; `save_safetensors` writes a new file and renames it over the old
one, which leaves loaded entries their values.

`load_npz` decodes every entry, and `load_npz_entry` decodes only the one it
names. NPZ names are logical names without the `.npy` suffix, and must be valid
UTF-8 and safe relative paths. Nx selects Store or DEFLATE compression
independently for each entry.

`load_gguf` reads a GGUF file's metadata, its tensors as an archive, and a
description of each tensor:

<!-- $MDX skip -->
```ocaml
let g = Nx_io.load_gguf "model.gguf" in
let info = Nx_io.Gguf.info "blk.0.ffn_up.weight" g in
let a = Nx_io.Gguf.tensors g
```

A tensor stored in a block format, such as Q8_0, loads as its bytes at `uint8`,
as do the SafeTensors dtypes Nx lacks. Bytes are never reinterpreted: their
meaning comes from code that knows the format.

## Saving and loading values

A value made of tensors, such as a model's parameters, has a structure, an
`Nx.Ptree.t` (see [Structures](06-structures.md)), which names each of its
tensors by its path: `blocks.0.w` is the field `w` of the first element of the
field `blocks`. `Archive.of_value` turns a value into the archive of its tensors
under those names, and `Archive.to_value` turns an archive back into a value:

<!-- $MDX skip -->
```ocaml
let () =
  Nx_io.save_safetensors "params.safetensors" (Nx_io.Archive.of_value mlp params)

let params =
  Nx_io.Archive.to_value mlp ~like:params
    (Nx_io.load_safetensors "params.safetensors")
```

Reading back needs a value of the same shape, `~like`: it supplies the record,
the list lengths, the options that are present, and each tensor's dtype and
shape. A program resuming its training has such a value, the one it would start
from. The tensors read back are the file's entries as stored, so nothing is read
from the disk until they are used, and nothing is converted: a value whose
dtypes differ from the file's fails, and never narrows what was saved.

`Nx.Ptree.field` puts a structure under a name, so one file holds several
sections, and `Archive.union` puts their archives together:

<!-- $MDX skip -->
```ocaml
let model = Nx.Ptree.field "model" mlp
let optim = Nx.Ptree.field "optim" (Vega.adam_ptree mlp)

let () =
  Nx_io.save_safetensors path
    (Nx_io.Archive.union
       [ Nx_io.Archive.of_value model params; Nx_io.Archive.of_value optim opt ])

let a = Nx_io.load_safetensors path
let params = Nx_io.Archive.to_value model ~like:params a
let opt = Nx_io.Archive.to_value optim ~like:opt a
```

A structure owns the names under its outermost fields, and every name when it
has none. Reading back is strict within those names and fails, naming the entry,
before any tensor is read:

- when a tensor of the value has no entry;
- when an entry has another dtype or shape, as in
  `model.blocks.1.w: shape [3] in the archive, [2; 3] in the value`;
- when an entry is named by no tensor of the value. A model of 12 blocks
  refuses a file of 24, since `model.blocks.12.w` names nothing.

Entries outside the structure's names are ignored, so reading `model` above
leaves the `optim` section alone.

## Files written elsewhere

A file another program wrote has its own names and layouts. Reading it into a
value is a function that asks for each entry by name, shape and dtype, and
rearranges it with Nx. `Archive.float` reads an entry stored as float16,
bfloat16, float32 or float64 at the float dtype the program computes in,
converting when the two differ:

<!-- $MDX skip -->
```ocaml
let linear a ~inputs ~outputs name =
  (* The file stores the weight as [outputs; inputs]. *)
  let w =
    Nx_io.Archive.float ~shape:[| outputs; inputs |] Nx.float32
      (name ^ ".weight") a
  in
  Nx.matrix_transpose w
```

A wrong configuration fails at the first entry it gets wrong, naming it. The
importer needs no value to start from, and at the file's own dtype every tensor
it returns is the file's entry, unread.

## Gzip streams

`gunzip` validates all members and their checksums before replacing the
destination. Concatenated members are supported. It decompresses as it reads,
in constant memory.

<!-- $MDX skip -->
```ocaml
Nx_io.gunzip ~src:"dataset.gz" ~dst:"dataset.bin"
```

## Errors and replacement

Malformed formats, unsupported dtypes, invalid NPZ names, and mismatches
between an archive and what is asked of it raise `Failure`. A name that cannot
name an entry, empty or given twice, raises `Invalid_argument`. NumPy, SafeTensors, and text helpers also report
filesystem failures as `Failure`; image and gzip operations preserve
`Unix.Unix_error` for filesystem failures.

`save_npy`, `save_npz`, `save_safetensors`, and `save_image` replace an existing destination by
default. Their `~overwrite:false` mode requires the destination not to exist.
Writes that replace a destination are completed through a temporary sibling so
an encoding failure does not leave a partially replaced file.

## Implementation and performance

Nx owns the ISC image and ZIP implementations used by `nx.io`, and takes
DEFLATE from Raven's `compress` package; it does not require system zlib,
libpng, libjpeg, or pkg-config. Image decoding writes into the final Nx buffer,
and a deflated NPZ entry is decompressed once, into memory that the tensor then
uses directly when its data is aligned. Use `load_npz_entry` for large archives
when only one tensor is needed.
