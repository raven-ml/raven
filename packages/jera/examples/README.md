# Jera Examples

Each example teaches one family of methods on a small problem and runs in a
few seconds at most. Start with `01-roots` and work through them in order.

| Example | Concept |
|---------|---------|
| [`01-roots`](./01-roots/) | Zeros of functions |
| [`02-systems`](./02-systems/) | Zeros of systems |
| [`03-minimization`](./03-minimization/) | Minima |
| [`04-linear-systems`](./04-linear-systems/) | Linear systems |
| [`05-quadrature`](./05-quadrature/) | Integrals |
| [`06-interpolation`](./06-interpolation/) | Interpolation and approximation |
| [`07-odes`](./07-odes/) | Ordinary differential equations |
| [`08-stiff-and-dae`](./08-stiff-and-dae/) | Stiff equations and algebraic constraints |
| [`09-sdes`](./09-sdes/) | Stochastic differential equations |
| [`10-splitting`](./10-splitting/) | Splitting methods |
| [`11-compile-and-batch`](./11-compile-and-batch/) | Derivatives, compilation and batching |

Run one from the repository root:

```bash
dune exec packages/jera/examples/01-roots/main.exe
```
