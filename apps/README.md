# Apps

Programs that do real work with raven, written to be read.

| App | What it does |
|---|---|
| [gpt-oss](gpt-oss/) | OpenAI's gpt-oss, a mixture-of-experts model: chat in the harmony format, on the CPU or compiled for GPUs |
| [tessera](tessera/) | TESSERA, an Earth-observation foundation model: pixel embeddings from a year of Sentinel-1 and -2, pretraining by Barlow Twins, distillation, on the CPU or compiled for GPUs |
